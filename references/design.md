# 设计阶段

下表是设计工作中可选的职责，同一聊天可以承担多项。具体聊天名称、数量和交付格式由项目决定。主控把用户目标转成一个可观察的任务，例如“学生能选答案、看到反馈并重新尝试”。

| 职责 | 输入 | 交付与验收 |
| --- | --- | --- |
| 交互原型 | 用户任务、业务规则、设备条件 | 交付关键路径和所需状态；要求试玩时提供可操作入口，用代表性输入走通完成与重试。 |
| 视觉风格 | 已知布局、参考风格、资源约束 | 交付可评审画面或可接入素材；检查指定尺寸、可读性和实际布局适配。 |
| 主控 | 当前目标、设计产物、用户已确认的取舍 | 核对版本与范围，从最终入口走查。需要视觉与原型结合时检查接入后的画面与操作。 |

探索风格可以先出方向稿；需要验证操作时先确定关键路径。并行时先约定画幅、状态及资源接口。交接时传递具体文件和使用说明。桌面走查、模拟触屏、真机体验和真人反馈分别记录实际证据。
